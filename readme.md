# Workout Plan Generator

An AI-powered workout plan generator built
using Python, Streamlit and Groq LLM.

## Features

- Generate personalized workout plans
- Supports different fitness goals
- Considers experience levels
- Customizable workout frequency
- Equipment and injury considerations

## Tech Stack

- Python
- Streamlit
- Groq API
- LLM Integration

## Installation

1. Clone the repository

2. Install dependencies

   pip install -r requirements.txt

3. Create a .env file and add:

   GROQ_API_KEY=your_api_key

4. Run the application

   streamlit run main.py
